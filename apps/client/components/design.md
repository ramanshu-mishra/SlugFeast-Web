# Design Guidelines for Components

## Color Palette
- **Primary:** neutral-950
- **Secondary:** neutral-800
- **Tertiary:** neutral-200
- **Other Neutrals:** neutral-50
- **Accent:** emerald-400, emerald-300

You may use different shades of these colors as needed, including lighter or darker variants for contrast, hover, or disabled states.

## Usage Principles
- Use **neutral-950** for main backgrounds or primary text in dark mode.
- Use **neutral-800** for secondary backgrounds, containers, or secondary text.
- Use **neutral-200** for borders, dividers, or subtle highlights.
- Use **neutral-50** for light backgrounds, input fields, or highlights in light mode.
- Use **emerald-400** and **emerald-300** for success states, highlights, or interactive elements (e.g., buttons, badges).

## Example Application
- Main container: background-neutral-950, text-neutral-200
- Card or modal: background-neutral-800, border-neutral-200
- Input fields: background-neutral-50 (light), background-neutral-800 (dark), border-neutral-200
- Primary button: background-emerald-400, text-neutral-950
- Secondary button: background-neutral-200, text-neutral-950
- Success badge: background-emerald-300, text-neutral-950

## Accessibility
- Ensure sufficient contrast between text and background.
- Use lighter shades for text on dark backgrounds and vice versa.
- For interactive elements, provide hover/focus states using slightly lighter or darker shades.

## Customization
- Adjust shades as needed for visual hierarchy or to match the overall brand tone.
- Use the accent colors sparingly to draw attention to key actions or statuses.
